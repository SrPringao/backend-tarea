API Finanzas Personales - GraphQL

API GraphQL de la etapa 2 (40 % restante de la lógica de negocio). Endpoint único: POST /graphql.

Autenticación: cabecera Authorization: Bearer TOKEN (se obtiene con POST /api/auth/login de la API REST). La mutación webhookExpense usa la cabecera X-API-Key. Los errores llevan extensions.code (UNAUTHENTICATED, FORBIDDEN, BAD_USER_INPUT, NOT_FOUND, CONFLICT).

Protecciones: profundidad máxima 8, costo máximo 5000, máximo 10 alias, 2000 tokens por consulta, 100 KB por petición JSON y 3 MB por subida (2 MB por archivo); en producción se desactivan la introspección y GraphiQL.

API Endpoints
http://localhost:3000/graphql
